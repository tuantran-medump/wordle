# Letterlock

An English word guessing game for the browser. Pick a word length from 5 to 8
letters and find the hidden word; you get one more guess than the word has letters.

- **Daily**: everyone gets the same word each day for each length.
- **Free play**: a new random word whenever you like.
- Green tile: right letter, right spot. Amber tile: in the word, wrong spot. Grey: not in the word.
- Progress and statistics are saved in your browser. Works on phones, with light and dark themes.

## Develop

```sh
npm install
npm run dev      # local dev server
npm test         # unit tests for the scoring logic
npm run build    # production build in dist/
```

## Word lists

`src/words/answers-N.txt` holds the words that can be the answer (common words,
with simple plurals and verb forms removed). `src/words/guesses-N.txt` holds every
word accepted as a guess. Both are generated by `scripts/build-words.cjs` from the
MIT-licensed npm packages [`wordlist-english`](https://www.npmjs.com/package/wordlist-english)
(SCOWL) and [`an-array-of-english-words`](https://www.npmjs.com/package/an-array-of-english-words):

```sh
npm install --no-save wordlist-english an-array-of-english-words
node scripts/build-words.cjs node_modules
```

## Deploy

`.github/workflows/deploy.yml` runs the tests and publishes the build to GitHub
Pages on every push to `main`. In the repository settings, set
**Pages → Build and deployment → Source** to **GitHub Actions** once.
